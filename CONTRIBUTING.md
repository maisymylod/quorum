# Contributing

## Getting set up

```bash
make install
make test
```

`make demo` runs the whole pipeline from a clean clone with no key and no network.

## What the gates enforce

`make test` runs the suite with a coverage floor. `make gates` runs the backtest and
enforces the thresholds in [`src/quorum/eval/gates.py`](src/quorum/eval/gates.py). CI
runs both. A change that makes the engine worse should fail a build rather than appear
as a slightly different number in a table nobody diffed.

Gates about prediction are enforced only when a real model produced the answers, and
report as skipped otherwise. The offline stub cannot pass them and should not be asked
to.

## House rules

**Numbers come from running the code.** `EVAL.md` and every published artifact are
generated by a make target. Do not edit them by hand, and do not put a figure in a
docstring or a README that no target regenerates.

**Say where a number came from.** Anything that reports an accuracy figure states the
provider that produced it. A table from the stub looks exactly like a table from a
model, and that difference is the whole value of the document.

**Fail rather than impute.** An unreadable model answer becomes NaN and is dropped
from a fit. A population that misses its target marginals stops the run. A contrast
with no draws does not claim to have resolved anything. Where a fallback is genuinely
correct, it is documented and tested rather than assumed.

**Test the property, not the call.** A test that asserts a function returned something
catches almost nothing. Assert that the pooling strength tracks real heterogeneity,
that the built graph exhibits the homophily it was configured with, that an unmeasured
difference is not reported as resolved.

**Determinism is a feature.** Synthesis, sampling, trait assignment, graph
construction and posterior draws are all seeded. If you add stochastic behaviour, seed
it and test that the same seed gives the same answer.

## Regenerating the vendored data

```bash
make data
```

Re-downloads roughly 650 MB of public source data into the untracked `data/raw/` and
rebuilds `data/vendor/`. Needs `pdftotext` (`brew install poppler`) for the codebook,
which is where verbatim question wording comes from. See
[`data/vendor/PROVENANCE.md`](data/vendor/PROVENANCE.md).
